# [Modulation Identification + DOA] MODANet: Multi-task Deep Network Application in Joint Modulation Classification and DoA Estimation [with MATLAB Code]

This paper proposes a multi-task deep convolutional neural network, MODANet, to achieve concurrent execution of modulation classification and direction of arrival (DOA) estimation. The network architecture incorporates multiple residual modules to effectively address the vanishing gradient problem. The study validates the multi-task learning efficiency of MODANet through various Y-shaped connection variants and hyperparameter tuning of the network. Results indicate that MODANet equipped with a single shared residual module, more filters, larger filter sizes, and longer signal lengths can enhance both modulation classification and DOA estimation performance, albeit increasing computational complexity. Therefore, selecting appropriate parameters for resource-constrained devices to balance accuracy and computational cost is crucial. The research also validates the impact of the channel on network performance based on two typical propagation channels models: pedestrian A and vehicle A. This paper's findings represent the first multi-task learning model based on deep learning, capable of handling two unrelated tasks: modulation classification and DOA estimation.
Introduction: Modulation types and the direction of arrival (DOA) of incoming radio signals are important radio characteristics in fields such as electronic intelligence, radio signal surveillance, cognitive radio, and MIMO communication. In military applications, surveillance and reconnaissance systems need to identify signal modulation types to locate enemy transmitting units, generate interference signals, and recover intercepted signals; in wireless communications, automatic modulation classification can be combined with adaptive modulation techniques to optimize transmission reliability and data rate according to channel conditions, enhancing the spectral efficiency of cognitive radio.
In recent years, deep learning-based automatic modulation classification methods have become a research hotspot, achieving breakthroughs in precision and computational complexity, but only accomplishing single modulation classification tasks. In terms of DOA estimation, traditional model-driven methods (such as beamforming, MUSIC, ESPRIT) have high precision and resolution but are susceptible to factors like hardware installation, antenna radiation patterns, and signal phase noise; existing data-driven methods have improved estimation accuracy but face issues such as complex processing flows, overfitting, vanishing gradients, and high computational complexity, and they only complete single DOA estimation tasks.
Multitask learning has been widely applied in fields such as natural language processing and computer vision, and has also been introduced into tasks like signal detection and modulation classification in wireless communication. However, there is currently no multitask learning network applied to the joint task of automatic modulation classification and DOA estimation. To address this, this paper proposes MODANet, a deep neural network based on multitask learning, which achieves synchronous execution of radio signal modulation classification and DOA estimation. It addresses gradient vanishing issues through residual modules, balances precision and computational cost with Y-shaped connection variants and hyperparameter tuning, and validates the network performance based on actual channel models.
Method Introduction 1 System Model Research: A cognitive radio receiver system model has been constructed. The receiver receives multipath modulated signals through an antenna array, which are preprocessed by a digital signal processor and then input into the MODANet to complete the joint task. Assuming the received signal contains both line-of-sight (LOS) and non-line-of-sight (NLOS) multipath components, mathematical models such as the received signal vector and antenna array steering vector are defined. After converting the complex signal into digital form, it is decomposed into I/Q samples and a high-dimensional data array is constructed as input for MODANet.
2. MODANet Network Architecture
★  
Input module: Constituted by input layer, convolutional layer, max pooling layer, batch normalization layer and ReLU activation layer in series. The size of the input layer matches the I/Q data array to complete preliminary feature extraction and preprocessing.
★  
Residual Module: It includes both main branch and skip connection branches. The main branch extracts features through two sets of convolution-pooling-normalization-ReLU layers, while the skip connection branch uses 1×1 unit filters to achieve feature reuse through an element-wise addition layer, effectively solving the vanishing gradient problem.
★  
Output module: The output module consists of convolutional layers, normalization layers, ReLU layers, fully connected layers, and Softmax layers. The number of neurons in the fully connected layer matches the number of modulation classification categories and DOA estimation categories respectively.
3 Loss function and training network total loss function is the sum of modulation classification loss and DOA estimation loss, both calculated using cross-entropy loss function. During training, equivalent weights are assigned to two tasks, and the network parameters are optimized through backpropagation.
4 Simulation settings: A synthetic signal dataset containing 12 types of modulations and 121 discrete angles of DOA was generated using MATLAB. Considering Gaussian noise, multipath propagation, attenuation, and delay as actual wireless communication impairments; an antenna array with a 5-element uniform linear array was set up, with a signal sampling rate of 1024. The dataset was randomly divided into 80% for training and 20% for testing. The network performance was evaluated by modulation classification accuracy and root mean square error of DOA estimation. The impact of different Y-shaped connection variants, number of filters, filter size, signal length, and channel model on performance was analyzed, and compared with existing models and traditional MUSIC methods.
Conclusion: This paper proposes a novel deep convolutional neural network, MODANet, which achieves joint execution of automatic modulation classification and DOA estimation tasks. The network employs multiple advanced residual modules and Y-shaped connection structures, paired with two output modules to output the modulation type and DOA category of the received signal respectively. Through verification of different Y-shaped connection variants, the optimal connection method was determined. Superparameter tuning experiments indicate that more filters, larger filter sizes, and longer signal lengths can improve the performance of modulation classification and DOA estimation, but also increase computational complexity. Therefore, selecting appropriate parameters for resource-constrained devices to balance precision and computational cost is key. This paper is the first deep learning-based multitask learning model to handle the unrelated tasks of modulation classification and DOA estimation.
Future research will focus on preprocessing techniques based on Fourier and wavelet transforms to construct MIMO systems, and optimize network architecture to further improve the accuracy of modulation classification and DOA estimation.
